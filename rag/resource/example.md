# 检索增强生成（RAG）入门指南

检索增强生成是一种将大语言模型与外部知识库结合的技术范式。本文档用于演示 Markdown 标题感知切分。

## 一、核心概念

RAG 的核心思想是：先检索相关知识，再基于检索结果生成答案，从而减少幻觉并提升事实准确性。

### 1.1 什么是检索

检索阶段负责从向量库或文档库中找出与用户问题最相关的文本片段。

#### 1.1.1 稀疏检索

基于关键词匹配的方法，如 BM25，适合精确术语查询。

##### 词袋模型简介

词袋模型忽略词序，仅统计词频，是稀疏检索的常见基础。

###### TF-IDF 简述

TF-IDF 通过词频与逆文档频率衡量词语重要性，常用于传统搜索排序。

##### 倒排索引

倒排索引将词语映射到包含该词的文档列表，是搜索引擎的核心数据结构。

#### 1.1.2 稠密检索

将文本编码为向量，通过相似度（如余弦相似度）召回语义相近的内容。

##### Embedding 模型

Embedding 模型把句子映射到高维向量空间，语义相近的文本距离更近。

###### 常见 Embedding 选择

可选用 OpenAI Embedding、BGE、Sentence-Transformers 等模型，按语言与场景选型。

### 1.2 什么是生成

生成阶段将用户问题与检索到的上下文一起输入大模型，由模型组织并输出最终答案。

#### 提示词设计要点

良好的提示词应明确角色、约束答案范围，并要求模型在证据不足时如实说明。

## 二、文本切分策略

文本切分质量直接影响检索效果：过粗会引入噪声，过细会丢失上下文。

### 2.1 固定长度切分

按固定字符数切分，实现简单，但可能在句子中间断开。

#### 优缺点

优点是可控、实现快；缺点是语义边界不友好，需要合适的 overlap 缓解。

### 2.2 递归字符切分

按分隔符优先级列表递归切分，通常优于纯固定长度切分。

#### 常用分隔符顺序

常见顺序为：段落、换行、句号、逗号，最后退化为按字符切分。

### 2.3 结构化感知切分

利用 Markdown、HTML、代码等结构信息，按标题或语义块切分。

#### Markdown 标题切分

`MarkdownHeaderTextSplitter` 会按 `#` ~ `######` 标题层级切分，并把标题写入 metadata。

##### 元数据用途

切分后的每个块可携带 H1、H2 等元数据，便于过滤检索范围或在答案中展示来源章节。

###### 本段验证用内容

如果你能看到本段被单独切出，并且 metadata 中包含从 H1 到 H6 的层级信息，说明测试文档工作正常。

## 三、实践建议

在真实项目中，应结合文档类型选择切分器，并用检索评估指标持续调参。

### 3.1 评估维度

关注召回率、精确率、答案正确率，以及切分后的平均块长度分布。

### 3.2 小结

合理切分是高质量 RAG 的基础；标题感知切分特别适合技术文档与知识库场景。
